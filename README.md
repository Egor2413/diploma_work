**REST API сервис для управления закупками товаров**

Полнофункциональный, оптимизированный backend-сервис для интернет-магазина с поддержкой каталога товаров, корзины, оформления заказов, асинхронной обработки задач и production-ready фичами (кэширование, логирование, rate limiting).

---

## 📋 Возможности

### Основной функционал
- ✅ **Каталог товаров** с категориями, поставщиками и расширенным поиском
- ✅ **Корзина покупок** с автоматическим подсчётом общей суммы
- ✅ **Оформление заказов** с мгновенной очисткой корзины
- ✅ **JWT-авторизация** (регистрация, получение и обновление токенов)
- ✅ **Импорт товаров** из YAML-файлов через админ-панель или API
- ✅ **Email-уведомления** клиентам и администраторам

### 🚀 Production-ready оптимизации
- ⚡ **Кэширование** ответов API (5 минут) для снижения нагрузки на БД
- 🔍 **Фильтрация, поиск и сортировка** товаров (по цене, названию, категории)
- 🛡️ **Rate Limiting** (защита API от злоупотреблений и DDoS)
- 📝 **Структурированное логирование** важных событий (заказы, импорт, ошибки)
- 🏥 **Health Check** эндпоинт для мониторинга работоспособности сервиса
- 🚀 **Асинхронные задачи** через Celery (отправка писем, импорт данных)

## 🛠 Технологии

### Backend & API
- **Python 3.10+**
- **Django 6.1** — основной веб-фреймворк
- **Django REST Framework 3.18** — построение REST API
- **djangorestframework-simplejwt** — JWT-аутентификация
- **django-filter** — продвинутая фильтрация и поиск
- **Celery 5.6** — асинхронная очередь задач

### Качество кода и CI/CD
- **pytest** & **pytest-django** — автоматизированное тестирование
- **black**, **isort**, **flake8** — форматирование и линтинг кода
- **GitHub Actions** — автоматический CI/CD пайплайн при каждом push

### База данных и кэширование
- **SQLite** (для локальной разработки)
- Архитектура полностью готова к переходу на **PostgreSQL**
- **LocMemCache** (встроенное кэширование Django)

### Документация
- **drf-spectacular** — автоматическая генерация OpenAPI/Swagger документации
